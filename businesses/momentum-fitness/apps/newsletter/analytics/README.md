# Newsletter Analytics

Track what each issue actually did. Opens are vanity; **leads are revenue** — so the column
that matters most is PHYSICS DMs/replies attributable to the send.

## Benchmarks to aim for (directional, local-business email)
- **Open rate:** 30–45% is healthy for an engaged local list. Below ~20% → fix subject lines
  and list hygiene.
- **Click rate:** 2–5% is solid. The CTA design and placement matter more than the copy length.
- **Replies:** an underrated signal — replies train inbox providers that you're wanted, and
  they're warm leads. Encourage them ("just reply to this email").
- **PHYSICS DMs:** the real scoreboard. Even a handful per send is a strong nurture result.

## How to learn one thing per issue
1. Change **one** variable at a time (subject angle, CTA placement, story vs. no story).
2. Note the result in "What we learned."
3. Fold the winner back into `../tools/prompt-library.md` so the next draft starts smarter.

## List hygiene
- Remove hard bounces; sunset subscribers who haven't opened in ~6 months (or run a win-back
  issue first — see the prompt library).
- A smaller engaged list beats a big dead one for both deliverability and morale.
