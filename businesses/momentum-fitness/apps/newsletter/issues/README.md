# Newsletter Issues

Ready-to-send newsletter issues for Momentum Fitness. Each issue is full copy — subject line,
preview text, and body — written in brand voice and pointed (softly) at Physics 101.

Each file is one issue. Copy it into your email tool (Mailchimp, Flodesk, ConvertKit, etc.),
paste the subject + preview into the header fields, and send. Personalize the bracketed bits
(member names, dates, current offer) before sending.

## Issues
- `issue-001-the-foundation-most-people-skip.md` — Education / "why physics matters." The
  flagship welcome-the-list issue. Pillar: Physics of Movement.
- `issue-002-why-your-progress-stalled.md` — Education + proof. Reframes a plateau as a
  movement-quality problem. Pillar: Physics of Movement → Proof.

## How to use
1. Pick the issue (or generate a new one with `../tools/prompt-library.md`).
2. Swap in this month's specifics (member story, any current Physics 101 intro details).
3. Confirm the **PHYSICS** keyword is the live one.
4. Send to the right segment (see `../strategy.md`); default is prospects.
5. Log results in `../analytics/`.
