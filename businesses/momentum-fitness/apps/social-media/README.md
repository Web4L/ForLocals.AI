# Momentum Fitness — Social Media Content

The social media content engine for **Momentum Fitness** (Pantego, TX). Positioning,
messaging, ready-to-post content, and planning tools in one place. Instagram is primary,
with TikTok and Facebook support.

**Primary objective:** drive qualified new leads into the **Physics 101** program (lead
capture via the DM/comment keyword **PHYSICS**) while building long-term brand authority as
the smart, principle-based fitness option.

## What's here
- `index.html` — the dashboard. Open it to browse everything in one styled view.
- `content/physics-101/` — ready-to-post content ideas and an Instagram batch.
- `calendar/` — monthly content calendar template + weekly themes.
- `ads/` — ad copy, creative briefs, offer frameworks (store as produced).
- `analytics/` — weekly/monthly performance insights and learnings.
- `tools/prompt-library.md` — copy-paste AI prompts with a Master Context Block.

## Brand context
This app reads the business's shared brand context from `../../brand/`:
`voice-tone.md`, `key-messaging.md`, `content-pillars.md`, and `move-framework.md`.
Those are the single source of truth — don't duplicate brand details here.
