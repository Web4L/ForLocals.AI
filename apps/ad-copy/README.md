# Ad Copy

Produce paid ad copy variations for Meta and Google — headlines, primary text, and creative
briefs — aligned to the business's primary offer and voice.

**Reads from brand context:** `brand`, `voice`, `key-messaging`, `primaryOffer`.
**Status:** planned (scaffold only).

- `prompts/` — ad-copy prompt templates and frameworks.
- `src/` — optional code (e.g. ad API integration), unused for now.
