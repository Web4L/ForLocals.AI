# Google Business Profile Posts

Generate Google Business Profile posts, offers, and updates that keep the listing active and
improve local/map-pack visibility.

**Reads from brand context:** `brand`, `voice`, `primaryOffer`.
**Status:** planned (scaffold only).

- `prompts/` — GBP post templates.
- `src/` — optional code (e.g. GBP API/Apify posting), unused for now.
