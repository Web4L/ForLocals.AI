# Social Media Content

Plan and generate on-brand social media content — Reel hooks, educational carousels,
captions, story series — and organize it on a content calendar. Instagram-first, adaptable
to TikTok and Facebook.

**Reads from brand context:** `brand`, `voice`, `key-messaging`, `content-pillars`.
**Produces:** ready-to-post content, a content calendar, and a prompt library tuned to the
business.

**Reference implementation:** `businesses/momentum-fitness/apps/social-media/` is a fully
built instance of this app, including a working dashboard (`index.html`), a prompt library
with a Master Context Block, and ready-to-post Physics 101 content.

- `prompts/` — reusable prompt templates (the business instance customizes these).
- `src/` — optional code (e.g. a generator or dashboard builder), unused for now.
