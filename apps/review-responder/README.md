# Review Responder

Draft on-brand replies to customer reviews across Google, Yelp, and Facebook — handling
both praise and complaints in the business's voice.

**Reads from brand context:** `brand`, `voice`.
**Status:** planned (scaffold only).

- `prompts/` — reply prompt templates by sentiment/scenario.
- `src/` — optional code (e.g. review API integration), unused for now.
