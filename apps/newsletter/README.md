# Newsletter Writing

Write recurring email newsletters in the business's voice — educational, on-brand, and
pointed at the primary offer. Produces full issues plus subject lines and preview text.

**Reads from brand context:** `brand`, `voice`, `key-messaging`.
**Status:** planned (scaffold only).

- `prompts/` — newsletter prompt templates.
- `src/` — optional code (e.g. send integration), unused for now.
