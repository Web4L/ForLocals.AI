## Benchmarks (directional, local-business email)
- **Open rate:** 30–45% healthy; below ~20% → fix subjects + list hygiene.
- **Click rate:** 2–5% solid.
- **Replies:** warm leads + they boost deliverability — encourage them.
- **{{CTA_KEYWORD}} leads:** the real scoreboard.
