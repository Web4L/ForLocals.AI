The email newsletter engine for **{{BUSINESS_NAME}}** ({{LOCATION}}). A recurring,

**{{OFFER}}** (lead capture via the keyword **{{CTA_KEYWORD}}**).

owns — nurture prospects and re-engage quiet subscribers — while reinforcing brand authority.

## What's here
- `strategy.md` — cadence, audience segments, and the issue anatomy.
- `issues/` — ready-to-send newsletter issues (full copy: subject, preview, body).
- `templates/` — the reusable issue structure + a subject-line library.
- `calendar/` — an editorial calendar with a theme per issue.
- `tools/prompt-library.md` — copy-paste AI prompts with a Master Context Block.
- `analytics/` — track opens, clicks, replies, and {{CTA_KEYWORD}} leads per issue.
