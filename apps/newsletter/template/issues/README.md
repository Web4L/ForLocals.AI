# Newsletter Issues

Ready-to-send issues for {{BUSINESS_NAME}}. Each issue is full copy — subject line, preview
text, and body — in brand voice and pointed (softly) at {{OFFER}}.

Each file is one issue. Copy it into your email tool, paste the subject + preview into the
header fields, personalize the bracketed bits, and send.

## How to use
1. Generate a new issue with `../tools/prompt-library.md` (or write one with the structure
   template).
2. Confirm the **{{CTA_KEYWORD}}** keyword is the live one.
3. Send to the right segment (see `../strategy.md`); default is prospects.
4. Log results in `../analytics/`.

> Add your first issues as `issue-001-<slug>.md`, `issue-002-<slug>.md`, … and list them in
> `../manifest.json` under "Newsletter Issues".
